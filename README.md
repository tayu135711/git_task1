# くうたび ミニサイト

Git の練習として作った、ゲーム「くうたび」の紹介ページです。

## 使ったコマンド

| コマンド | 使った場面 |
|---|---|
| git init -b main | リポジトリを作った |
| git add . / git commit | 変更を記録した |
| git switch -c | ブランチを作って移動した |
| git merge | ブランチを合流させた |
| git branch -d | マージ済みのブランチを削除した |
| git tag -a | v1.0 の目印を付けた |
| git log --oneline --graph | 履歴の枝分かれを確認した |

## 学んだこと

Git は、コード量が増えても変更履歴を管理できるので便利だと分かりました。
ブランチを使うと、自分だけの作業フォルダのように、main を壊さずに作業できます。
コンフリクトが起きたときも、今回学んだコマンドややり方を知っていれば対応できると学べました。
今いる状態が分からなくなったときは、git status で確認すればいいと分かりました。
